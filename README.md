## 📱 About Mor Panchayat

**Mor Panchayat** is a digital platform designed to make Panchayat services and village information easier to manage and access.

The application provides different features and access levels for:

- Sarpanch
- Panchayat Members
- Villagers

The app is continuously updated with new features, improvements and bug fixes.
