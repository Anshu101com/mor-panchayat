# ✨ What is Mor Panchayat?

**Mor Panchayat** is a digital Panchayat communication platform designed to make communication between villagers and their Panchayat easier, faster and more transparent.

Instead of depending completely on physical notices or word-of-mouth communication, Panchayat updates can be delivered directly through the app.

The goal is simple:

> **Make important Panchayat information available to every villager, directly on their phone.**

---

# 🎯 Our Vision

Mor Panchayat aims to create a simple digital bridge between:

# 📢 Digital Announcements

One of the main features of Mor Panchayat is the digital announcement system.

A Panchayat member can publish an announcement and villagers can see it inside the application.

### Example

```text
🏛️ Panchayat
      │
      ▼
📢 Create Announcement
      │
      ▼
☁️ Supabase
      │
      ▼
🔄 Realtime Update
      │
      ▼
📱 Villager App
      │
      ▼
👨‍🌾 Villager receives update
```

This allows important information to reach villagers without requiring physical notice distribution.

# ⚡ Realtime Architecture

Mor Panchayat uses Supabase Realtime for live application updates.

```text
              ┌─────────────────┐
              │     SUPABASE    │
              │                 │
              │   PostgreSQL    │
              │      +          │
              │    Realtime     │
              └────────┬────────┘
                       │
             ┌─────────┴─────────┐
             │                   │
             ▼                   ▼
       🏛️ Panchayat          👨‍🌾 Villager
             │                   │
             └─────────┬─────────┘
                       │
                       ▼
                 🔄 LIVE DATA
```

When a Panchayat announcement changes, connected clients can refresh their announcement list automatically.

---

# 🔐 Security

Mor Panchayat uses Supabase Authentication and Row Level Security.

Security-related components include:

* 🔑 Supabase Authentication
* 🛡️ Row Level Security
* 🔐 Protected database access
* 👤 Role-based application behavior
* 🔒 Authenticated user sessions
* ☁️ Server-side Edge Functions
* 🔑 Secure password reset flow

Sensitive Supabase service-role credentials are **never stored inside the Flutter application**.

---

# 🔑 Forgot Password

The villager password recovery flow uses multiple verification steps.

```text
📱 Mobile Number
       │
       ▼
👤 Name
       │
       ▼
👨 Father's Name
       │
       ▼
🎂 Date of Birth
       │
       ▼
🔐 Verification
       │
       ▼
🔢 OTP
       │
       ▼
🔑 New Password
       │
       ▼
✅ Password Updated
```

The verification logic is handled through a Supabase Edge Function.
