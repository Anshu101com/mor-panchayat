## 🌱 About Mor Panchayat

**Mor Panchayat** is a digital platform designed to bring essential Panchayat communication and services into one simple, accessible place.

The goal is straightforward:

> **Make Panchayat information easier to access, communication easier to manage, and village services more connected.**

Mor Panchayat is being developed with a focus on simplicity, accessibility and a clean government-service experience.

---

## ✨ What Has Been Built

### 👤 Panchayat Member Management

Panchayat administration can manage members from a centralized system.

* Add Panchayat members
* View member information
* Manage member profiles
* Ward-based information
* Role-based access
* Member information management

---

### 🏛️ Sarpanch Dashboard

A dedicated dashboard provides an overview of Panchayat activity.

**Dashboard information includes:**

* Panchayat people
* Members
* Villagers
* Ward information
* Recent announcements
* Profile information

The dashboard is designed to provide important information at a glance.

---

### 📢 Announcements

Panchayat announcements can be published digitally so that important information can reach members and villagers more efficiently.

Features include:

* Create announcements
* Publish announcements
* View recent announcements
* Announcement updates
* Announcement discussions

---

### 🧑‍🌾 Villager Access

Mor Panchayat is designed to support villagers directly.

The villager system includes:

* Mobile-based access
* Account registration
* Secure login
* Personal information
* Ward information
* Panchayat announcements
* Account recovery

The objective is to make Panchayat information available without requiring villagers to depend entirely on physical communication.

---

### 🌐 Bilingual Experience

Mor Panchayat is designed with both **English and Hindi** in mind.

Users can switch between:

**English 🇬🇧**

and

**हिन्दी 🇮🇳**

This helps make the platform more accessible to people with different language preferences.

---

## 🔐 Role-Based Access

Different users have different responsibilities.

```text
                    MOR PANCHAYAT
                         │
          ┌──────────────┼──────────────┐
          │              │              │
       Sarpanch        Member        Villager
          │              │              │
       Manage          View          Access
       Panchayat      Information    Services
          │              │              │
          └──────────────┼──────────────┘
                         │
                    Panchayat
                    Information
```

This structure helps keep administrative functions separate from general user access.

## 📱 Designed for Real-World Use

Mor Panchayat focuses on a simple experience rather than unnecessary complexity.

### Design principles

* Clean interface
* Simple navigation
* Large touch-friendly controls
* Clear information hierarchy
* Hindi + English support
* Government-service inspired design
* Lightweight user experience
* Consistent visual language

---

## 🔄 Automatic Updates

Mor Panchayat includes an update system designed to notify users when a newer release is available.

The system can distinguish between:

* Optional updates
* Required updates
* Critical updates

This allows important releases to reach users without requiring them to manually check for every new version.

## 📣 Communication
